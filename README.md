# Schoolzy Frontend

The official frontend repository for the **Schoolzy platform** — a modern educational management system built with React, TypeScript, and Vite.

## Overview

This is a TypeScript-first React application providing a responsive, performant user interface for the Schoolzy platform. The project leverages modern web technologies and best practices for development, testing, and deployment.
